# SOC Fundamentals — TryHackMe

## Overview

This repository contains my notes, key concepts, and learning outcomes from completing the **SOC Fundamentals** room on TryHackMe.

The room introduced the core responsibilities, workflows, and tools used inside a Security Operations Center (SOC), along with the fundamentals of incident detection and response.
